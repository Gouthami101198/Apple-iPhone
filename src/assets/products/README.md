# Your own product photos

Drop a photo here named after a product key and it replaces the drawn illustration
automatically (jpg, png, webp or avif):

| Page      | File names                                                        |
|-----------|-------------------------------------------------------------------|
| Mac       | mac-hero, macbook-air, macbook-pro, imac, mac-mini, mac-studio    |
| iPad      | ipad-hero, ipad-pro, ipad-air, ipad, ipad-mini                    |
| Watch     | watch-hero, watch-ultra, watch-series, watch-se                   |
| TV & Home | tv-hero, apple-tv, homepod, homepod-mini                          |

Example: `src/assets/products/macbook-air.png`
